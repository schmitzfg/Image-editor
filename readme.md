# Simple Image Editor

A desktop image editor built with Python, CustomTkinter, and Pillow.

The application allows users to open, edit, preview, and save images using a modern graphical interface with real-time image processing.

## Features

### Basic Editing
- Open JPG and PNG images
- Save edited images
- Image preview
- Flip image horizontally
- Rotate image by 90°

### Image Adjustments
- Brightness
- Contrast
- Saturation
- Sharpness
- Blur
- Color Temperature

### Effects & Filters
- Grayscale
- Sepia
- Posterize Filter
- Vintage Effect
- Vignette Effect
- Bloom Effect
- Pixelation
- Emboss
- Edge Detection
- Noise
- Gaussian Noise

### Resize & Compression
- Resize images
- Keep Aspect Ratio option
- JPEG quality adjustment
- PNG compression support

### Presets
Built-in presets:

- Retro
- Cinema
- B&W
- Cold
- Warm
- Cyberpunk
- Dreamy

### User Interface
- Modern dark theme
- Tab-based controls
- Live preview
- Hover button effects
- Fullscreen image display option
